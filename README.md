# 《探究浮力产生的原因》互动演示网页

这是一个面向初中物理课堂的浮力原理互动演示网页。它通过可拖拽物体、受力矢量、实时数据和底部嵌入模型，帮助学生直观理解：浮力产生的原因是液体对物体上下表面的压力差。

## 功能特点

- 拖动物体：改变物体在液体中的位置，观察浸入深度变化。
- 勾选受力：可单独显示上表面压力、下表面压力、浮力、重力。
- 实时数据：同步显示深度、上下表面压强、压力差、浮力、重力、净力等数据。
- 参数调节：可修改物体密度、物体大小，并切换水、盐水、蜂蜜等液体类型。
- 难点突破：支持底部嵌入物体模型，用于演示下表面无液体接触时不产生浮力的特殊情境。

## 使用方法

1. 下载本仓库源码。
2. 用浏览器直接打开 `index.html`。
3. 在页面中拖动绿色物体，观察受力箭头和右侧数据变化。
4. 根据教学需要勾选或取消显示不同力，调整物体密度、物体大小和液体类型。
5. 勾选“底部嵌入物体”，观察下表面无液体时浮力为 0 的情况。

## 教学用途

本网页适用于“探究浮力产生的原因”课堂演示、学生分组探究和课后复习。它将教材中较抽象的压力差关系转化为可视化过程，便于学生从“背公式”转向“看过程、读数据、会解释”。

## 物理说明

液体压强随深度增加而增大。物体浸入液体后，下表面通常比上表面更深，因此下表面受到的向上压力大于上表面受到的向下压力，二者的压力差表现为浮力。

对于规则物体的典型情境，可用下式理解：

```text
F浮 = F向上 - F向下
```

也可结合压强与面积理解为：

```text
F浮 = (p下 - p上) × S
```

需要注意：压强差本身不是浮力，压强差需要结合受力面积转化为压力差，最终由上下表面压力的合力形成浮力。
